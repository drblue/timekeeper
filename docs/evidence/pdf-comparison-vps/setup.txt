with about 2,273 MiB available, and after it completed with about 2,392

Docker health fields. The first non-root smoke run exposed restrictive

corrected build ran with a 300-second timeout and a two-second guard for
host available memory, disk space and the existing containers' states.

private PID and IPC namespaces, Docker init, no external networking or

limits were 1.5 vCPU quota across two visible vCPUs, 2 GiB memory, zero
swap allowance and 256 tasks. The private tmpfs and shm limits were 512
MiB each; used pages count against the memory cap. The host is a KVM VPS.

The original Playwright v1.65.0 Docker seccomp profile permits namespace
creation, but with all outer capabilities dropped it blocked the chroot
Chromium uses to isolate its renderer in a nested namespace. The final
temporary profile changed only the chroot rule's capability gate.
The kernel still enforces the chroot capability check. The test used
Docker AppArmor, dropped all Docker capabilities, and set no-new-privileges.
The preflight launched the exact production-candidate Chromium helper,
generated a probe PDF, inspected the real launch arguments, and observed
the Chromium renderer in a nested PID namespace with two seccomp filters
against the surrounding container process's one.
